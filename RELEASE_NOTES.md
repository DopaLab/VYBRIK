# VYBRIK 1.4.0 — Ad-Free Edition

This is the first public GitHub release of VYBRIK's fully ad-free Android edition.

## Highlights

- Urban-modern countdown dashboard
- Accessible five-column time picker
- Easy 12-hour and 24-hour switching
- Rising-sun AM and setting-sun PM controls
- Alarm, notification, and silent countdown modes
- Custom alarm audio import and recent-sound memory
- Daily or selected-weekday repetition
- User-created, renamed, and removable tabs
- Tap any countdown to edit it
- Optional titles and notes without placeholder labels
- No advertisements, premium gate, or required account

## Installation

Download `Vybrik-Pro-v1.4.0-release-signed.apk` from the GitHub release assets. On first install, Android may ask you to allow APK installation from your browser or file manager.

The APK requires Android 8.0 or newer and is signed with the DopaLAb release certificate.
